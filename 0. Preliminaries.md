# Sets

A set is a collection of objects called elements
elements can be anything
- pair of numbers
- triangles
- numbers
- etc..

There are 2 ways to declare a set:
	1. List the elements of the set $$A = \{1, 1, 2, 3, 5, 8, 13\}$$
	2. By defining the properties of its elements $$ A = \{ a | a \in \mathbb{Z}, a = k * 3, k \in \mathbb{Z}\}$$$$ B = \{x | x^2 \le 5, x \in \mathbb{R}\}$$
