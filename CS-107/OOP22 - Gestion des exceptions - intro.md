#introprog 

En programmation il faut pouvoir gérer des erreurs lancées par le programme. 

-> Gestion des exceptions

Une `Exception` est un objet qui est "lancé" par une erreur. -> Permet d'informer le reste du programme ce qu'il faut faire

Quatres mécanismes :
- Lancement d'une exception avec `throw`
- Une méthode dans laquelle se passe l'exception, dans un block dénoté `try`
- Attraper l'exception avec `catch
- Faire le ménage avec `finally`
