#introprog 

Il est possible de redéfinir une fonction dans une sous-classe qui était déjà définie dans sa super-classe. On parle donc de redéfinition

On peut masquer une fonction ou attribut, ce qui consiste à nommer une fonction/attribut avec le même nom qu'une qui est définie dans la super-classe

On peut toujours accéder aux fonctions définies dans les super-classes
```Java
super.methode();
super.attribut;
```
