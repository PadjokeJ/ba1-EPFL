#analyse 
On note l'ensemble des nombres complexes $\mathbb C$. C'est un corps.

>[!Définition]
>On note $\mathbb C$ l'ensemble des paires de réels, $z = (x,\; y)$, muni de 
>- l'addition $$z + z' = (x + x',\; y + y')$$
>- la multiplication $$z \cdot z' = (x\cdot x' - y \cdot y', \; xy' + x'y)$$

# Le nombre $i$

On définit le nombre complexe $$i := (0, \; 1)$$
On remarque que$$(-i)^2 = i^2 = (-1, 0)$$
Si on a l'équation $z^2 + 1 = 0$, alors $i$ et $-i$ sont des solutions

# Partie Réelle ou Imaginaire

On peut donc écrire $\forall(x, y)\in \mathbb C$:$$(x,y)=(x,0) + (0,y) = (x, 0)+y\cdot(0,1) \equiv x + y\cdot i$$
Ainsi : $$(x,y) = x + y\cdot i$$Ce qui nous permet de retrouver la loi de multiplication

>[!Définition]
>- $Re(z) := x$ : la partie réele de $z$
>- $Im(z) := y$ : la partie imaginaire de $z$


# Conjugué et Module

Pour l'identité $(x+iy)(x-iy)$, on trouve $x^2 + y^2$
>[!Définition]
>- $\bar z$ est le conjugué de $z$, t.q $\bar z := x - y\cdot i$
>- $\vert z \vert$ est le module de $z$, t.q $\vert z \vert := \sqrt{x^2 + y^2}$
