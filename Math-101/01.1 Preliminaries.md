# Sets

A set is a collection of objects called elements
elements can be anything
- pair of numbers
- triangles
- numbers
- etc..

## Declaration

1. List the elements of the set 
	   $A = \{1,\; 1,\; 2,\; 3,\; 5,\; 8,\; 13\}$
2. By defining the properties of its elements 
	   $A = \{ a \;|\; a \in \mathbb{Z},\; a = k * 3,\; k \in \mathbb{Z}\}$
	   $B = \{x \;|\; x^2 \le 5,\; x \in \mathbb{R}\}$

## Notation

$A, B$ are two sets, $a, b$ are elements
- we write $a \in A$ => "a belongs to A"
- we write $a \notin A$ => "a doesn't belong to A"
- we write $A \subset B$ => "A is a subset of B"
- we write $A \subseteq B$ => "A is a subset of B" alternative notation
- we write $A \not \subset B$ => "A is not a subset of B"
- we write $A \not \subseteq B$ => "A is not a subset of B"
- we write $A \subsetneq B$ => "A is a subset of B but is not equal to B"
- we write $A = B$ => "A and B have the exact same elements"
	- $\forall a \in A,\; a\in B$ and $\forall b \in B,\; a \in A$ 
- we write $\varnothing$ for an empty set => $\varnothing = \{\}$
> [!Info] $\varnothing \subset A$ and $\varnothing \subset \varnothing$
### Examples 
#### Belonging

$X = \{1,\; 2,\; d\}$
$1 \in X$ , $2 \in X$, $5 \notin X$

#### Subsets

$X = \{1,\;2,\;d\}$
$Y = \{1,\;2\}$
$Z = \{1,\;5\}$
$Y \subseteq X$
$Z \not \subseteq X$ because of $5$

## Operations with sets

- Union => all elements contained in either $A$ and $B$
  $A \cup B =\{x \;|\; x \in A \text{ or } x \in B\}$
- Intersection => all elements contained in only $A$ and $B$
  $A \cap B =\{x \;|\; x \in A \text{ and } x \in B\}$
- Complement => an element contained in $A$ but not $B$ (Substraction)
  $A \;\backslash\; B =\{x \;|\; x \in A \text{ and } x \notin B\}$
- Cartesian Product
  $A \times B := \{ (a,\;b) \;|\; a \in A,\; b \in B \}$ 
> [!Info] The pair is ordered: $(a,\;b) \not= (b,\;a)$

> [!Info] If $A$ and $B$ are finite sets, $|A|$ and $|B|$ are the number of elements in $A$ and $B$ => $|A \times B| = |A| \times |B|$ 

### Examples

- Symmetric difference:
  $(A \; \backslash \; B) \cup (B \; \backslash \; A) = (A \cup B) \; \backslash \; (A \cap B)$
  all the elements of $A$ or $B$ which are not in $A$ and $B$
- Exercise 
  $(A \cup B \cup C) \;\backslash\; (A \cap B \cap C)$
- Cartesian product 
  $A=\{2,\;3,\;5\},\; B=\{1,\;6\}$
  $A \times B = \{(2,\;1),\;(3,\;1),\;(5,\;1),\;(2,\;6),\;(3,\;6),\;(5,\;6)\}$ 
  $\mathbb{R}^2 = \mathbb{R}\times\mathbb{R} = \{(a,\;b)\;|\; a \in \mathbb{R},\; b \in \mathbb{R}\}$
## Standard sets
- $\mathbb{N}$ : positive integers
- $\mathbb{Z}$ : all integers
- $\mathbb{R}$ : all real numbers
- $\mathbb{Q}$ : all rational numbers
> [!Info] Adding a star $*$ at the end of a set excludes $0$

#### Sum and product notation

Let $l \lt k$ 
Then : 
$$\sum_{i = l}^k a_i= a_l + a_{l + 1} + \dots + a_i + \dots + a_{k-1} + a_k$$
$$\prod_{i = l}^k a_i = a_l * a_{l + 1} * \dots * a_i * \dots * a_{k-1} * a_k$$

##### Alternate proof
$\sum_{i = 1}^\infty \frac{9}{10^i}$ -> $a_i = \frac{9}{10^i}$
so how do we make sense of this infinite sum ?
- We can consider it to be finite :
  $\sum_{i = 1}^k \frac{9}{10^i}$ 
  we gradually increase $k$ 
  there will always be a small distance between $a_i$ and $1$
  so : $\sum_{i = 1}^k \frac{9}{10^i} \lt 1$ -> $\lim\limits_{k \to \infty} \sum_{i = 1}^k \frac{9}{10^i} = 1$
