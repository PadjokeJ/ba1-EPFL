>[!théorème] Changement de variable dans l’intégrale définie
>$$\int_a^b f(g(t))g’(t) dt = \int_{g(a)}^{g(b)} f(x) dx$$

Si on a 
$$x = g(t)$$
On a donc 
$$F(x) = F(g(x)) = G(t)$$
On calcule $G(t)$
$$G(t) = \int f(g(t)) g'(t) \ dt$$
Si $g$ est inversible alors on a 
$$F(x) = G(t) = G(g^{-1}(x))$$
On écrit la relation
$$\int f(x) \ dx = \int f(g(t)) g'(t) \ dt$$
>[!Example] Exemple
>On a l'intégrale indéfinie
>$$\int \sin 2x \ dt$$
>On a donc $t = 2x$, et on pose $g(t) = t/2$ 
>$$G(t) = \int f(g(t)) g'(t) dt = \frac12 \int \sin t \ dt = -\frac12 cos(t) + C$$
>Et on inverse 
>$$F(x) = G(2x) = -\frac12 \cos (2x) + C$$
