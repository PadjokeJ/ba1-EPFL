>[!TLDR]+ Définition
>Un réel $x_*$ est un point fixe si $g(x_*) = x_*$

==L'existence d'un point fixe peut être utile pour l'étude d'une suite définie par récurrence. ==
Si par exemple c'est la condition initiale d'une suite, alors on sait que cette suite est constante.

>[!Check]+ Théorème
>Si une suite définie par récurrence est convergente, alors elle converge vers un point fixe

Mais une suite peut contenir plusieurs points fixes, le théorème indique qu'elle tend vers un point, MAIS N'INDIQUE PAS LEQUEL
