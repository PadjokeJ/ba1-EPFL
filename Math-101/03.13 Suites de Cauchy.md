#analyse 
On sait que si une suite $(a_n)$ converge, alors la distance entre deux éléments consécutifs tendent vers 0$$dist(a_n, a_{n+1}) \to 0 \qquad \text{quand } n \to \infty$$
Mais on peut aussi dire que deux éléments divers, non-consécutifs, ont également une distance qui tend vers 0 $$dist(a_m,\; a_n) \to 0 \qquad \text{quand } m, \; n \to \infty$$
>[!tldr] Définition
>$(a_n)$ est une suite de Cauchy si $\forall \epsilon \gt 0, \exists N \in \mathbb N$ tel que $$dist(a_n, a_m) \le \epsilon \quad \forall m, \; n \ge N$$

>[!Check] Théorème
>Dans $\mathbb R$, une suite ne converge que si c'est une suite de Cauchy
