## What is this course about  

- Real and complex numbers
- Sequences and their limits (
- Series : $$ e_1 + e_2 + ... + e_\infty $$
- Theory of functions
	- Operations with functions
	- Continuity
	- Derivatives
	- Integration
- Rigorous logic:
	- Definitions => give properties
	- Theorems => statements that we will show
	- Proofs => Define what a real number is
		- Constructive 
		  $A \implies B \implies C \implies D$
		- Contradiction 
		  Example :  
		 $\sqrt{3} \notin \mathbb{R}$
		 $\text{ assuming a and b are prime :}$
		 $\sqrt{3} = a/b$
		 $\implies (\sqrt{3})^2 = ( \frac{a}{b} )^2$
		 $\implies 3 = (\frac{a}{b})^2$
		 $\implies 3 * b^2 = a^2$  
		 $\implies \text{3|a such as a = 3 * r}$
		 $\implies b^2 = 9r^2$ 
		 $\implies b^2 = 3r^2$ 
		 $\implies \text{3|b}$
		 $\implies \text{a and b are not prime}$
The statement is therefore not true : $\sqrt{3}$
