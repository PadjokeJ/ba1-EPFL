
#analyse

On peut utiliser [[01.3 Ordre|les relations d'ordre]] pour définir des intervalles, sous ensembles des constructions de nombre

# Intervalles bornées 

- $[a,\;b]$ 
- $]a,\;b]$
- $[a,\;b[$
- $]a,\;b[$

Si la parenthèses carrée est orientée vers un délimiteur, on dit que l'intervalle est **fermée**

Si la parenthèse carrée est orientée vers l'extérieur, on dit que l'intervalle est **ouvert**

Exemple d'une intervale :
```handwritten-ink
{
	"versionAtEmbed": "0.3.4",
	"filepath": "Ink/Writing/2025.9.16 - 14.36pm.writing"
}
```

# Intervalles non bornées

Intervalles qui sont ouvertes vers l'infini

Exemple : 
$[a, \; + \infty[$ 

# Intervalles des ensembles

On peut délimiter un ensemble de cette manière

Les positifs :
$$\begin{align} 
\mathbb R_+ &:=& \{x \in \mathbb R : x \ge 0\} &=& [0, +\infty[,\\
\mathbb R_+^* &:=& \{x \in \mathbb R : x \gt 0 \} &=& ]0, +\infty[
\end{align}$$
Les négatifs :
$$\begin{align} 
\mathbb R_- &:=& \{x \in \mathbb R : x \le 0\} &=& ]-\infty, 0],\\
\mathbb R_-^* &:=& \{x \in \mathbb R : x \lt 0 \} &=& ]-\infty, 0[
\end{align}
$$
