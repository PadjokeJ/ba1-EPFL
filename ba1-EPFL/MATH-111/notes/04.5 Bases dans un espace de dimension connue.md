> [!Theorem] Théorème -- base par famille génératrice
> Pour $V$ un $\mathbb{R}$-espace vectoriel avec $\dim V=n$, alors si $S\subset V$ est une **famille génératrice** avec $n$ éléments, alors $S$ est une base de $V$

> [!Theorem] Théorème -- Base par famille libre
> Pour $V$ un $\mathbb{R}$-espace vectoriel avec $\dim V=n$, alors si $S'\subset V$ est une **famille libre** avec $n$ éléments, alors $S'$ est une base de $V$
