# Logarithmes et leurs règles 

- $\ln(xy) = \ln(x) + \ln(y)$, 
- $\ln\left( \frac{x}{y} \right) = \ln(x)-\ln (y)$,
- $\ln(x^{c}) = c\ln (x)$,
- $\ln(1)=0$
# Trigonométrie

Les fonctions $\sin, \cos, \tan$

Ainsi que les règles du style
- $\tan x=\frac{\sin x}{\cos x}$
- $\cot x = \frac{\cos x}{\sin x}$
- $\sin(x\pm y) = \sin x\cos y\pm \cos x\sin y$
- $\cos(x\pm y)=\cos x\cos y\pm \sin x\sin y$

Ainsi que leurs valeurs à des angles spécifiques
