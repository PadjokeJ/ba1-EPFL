If we take a circle, the full angle of the circle is equal to the arc length, so $\theta = 2\pi$, this is called radians. We can get the angle between two [Vectors](00.1%20Vectors.md) 
$90° = \pi/2$
$180° = \pi$

## Trigonometric circle

$cos\frac{\pi}{6} = \frac{\sqrt{3}}{2}$
$sin\frac{\pi}{3} = \frac{\sqrt{3}}{2}$
$sin\frac{\pi}{6} = \frac{1}{2}$
$cos\frac{\pi}{3} = \frac{1}{2}$
$cos(\frac{\pi}{4}) = sin(\frac{\pi}{4}) = \frac{\sqrt{2}}{2}$
$cos 0 = 1$
$sin 0 = 0$
$cos \frac{\pi}{2} = 0$
$sin \frac{\pi}{2} = 1$

We can use the trigonometric circle as a guide  

sin is uneven => sin-theta = -sin theta
cos is even => cos -theta = cos theta

## Trigonometric identities

$cos^2 \theta + sin^2 \theta = 1$
$tan^2\theta = \frac{1}{cos^2\theta} - 1$

$cos\; a + b = cos\; a * cos\; b - sin\; a * sin\; b$
$sin\; a + b = sin\; a * cos\; b + sin\; b * cos\; a$
