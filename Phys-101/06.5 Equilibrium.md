#phys 

If we have an object moving along an axis and a position zero of that axis. If we also have (eg for x axis) $${dE_p\over dx}(x_0)=0$$
We deduce that the force at that position is $0$, therefore the object is motionless at that point. We call this position **of equilibrium**. At this position there is either a minimum or maximum of potential energy

If it is a maximum, then it is unstable

If it is a minimum, then it is stable
