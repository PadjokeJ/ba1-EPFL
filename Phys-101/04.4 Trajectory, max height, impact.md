When we seek the trajectory, we can substitute t with the position on the $x$ axis.

We therefore have, with $t = x/(v_0 \cos \theta)$ $$z(x)=-\frac g {2v_0^2 \cos ^2 \theta} x^2 + \tan \theta \; x$$
We can see that the form of the trajectory is a downwards parabola, s.t. $z(x)= ax^2 + bx$ -> $a \lt 0$


## Max height
We can therefore solve the trajectory for the highest point.
We call the point atop the max height $S$. $r_S = (x_S, 0, z_S)$ 
We know that the object is neither going up nor down at the highest point of the trajectory. -> $v_{S,y} = 0$ -> $-gt + v_0 \sin \theta = 0$ -> $$\frac{v_0 \sin \theta}g = t$$We can then get the position of this point

## Impact point 

We can also solve for the point of impact. We have $r_{A, z}(t) = 0$ -> $0=-\frac g {2v_0^2 \cos ^2 \theta} x^2 + \tan \theta \; x$ ->$$x_A = \frac{2v_0^2\cos\theta\sin\theta} g$$
