Not all movement analysis is in a fixed reference frame. Per example, if we are in a train, and want to analyse the movement of an object inside of the train, we must use a referential that is moving. 
A referential can therefore move and rotate in relation to another referential

let $\mathcal R$ be a fixed reference frame using the Cartesian coordinate system $(O, \overrightarrow{x_1}, \overrightarrow{x_2}, \overrightarrow{x_3})$
let $\mathcal R'$ a reference frame in motion relative to $\mathcal R$, using the cartesian coordiantes $(A, \overrightarrow{y_1}, \overrightarrow{y_2}, \overrightarrow{y_3})$

There can be issues when trying to link both referentials together

We can separate the movement of R' into a translation and a rotation
The translation corresponds to the movement of $A$ in $\mathcal R$ 
The rotation corresponds to the rotation of the axes $e_{y_i}$ in relation to $e_{x_i}$

Both movements can be in relation with time!!
