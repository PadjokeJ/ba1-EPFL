## Derivatives 

$y = f(x)$, the derivative $f'(x)$ is the slope of $f(x)$ at any given point $x$ 
it is obtained by the limit of $\frac{\Delta y}{\Delta x}$ when $\Delta x = 0$ 
$df = f(x + dx) - f(x)$

It is useful to know some common derivatives

| func      | deriv           |
| --------- | --------------- |
| $cos\; x$ | $-sin\; x$      |
| $sin\; x$ | $cos\; x$       |
| $tan\;x$  | $1 / cos ^{2x}$ |
| $ln\; x$  | $e^x$           |
| $x^n$     | $n*x^{n-1}$     |
$(f*g)' = f'*g + f*g'$ 
$(f[g(x)])' = g'(x) * f'[g(x)]$

## Anti derivatives (primitives _fr_)

$F'(x)=f(x)$ 

The anti derivative finds the area under a curve, so $F(x)$ is the ==area== between $f(x)$ and the $x$ axis
