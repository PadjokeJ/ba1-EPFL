International System of Units (SI) 
In mechanics, three are mostly used : 

| Name   | Unit      | Symbol |
| ------ | --------- | ------ |
| Time   | Seconds   | s      |
| Length | Meters    | m      |
| Mass   | Kilograms | kg     |
## Dimensional analysis

If the variable $h$ is of the length units, we can write $dim \; h = L$. 
$L$ is used to represent length. We can therefore calculate functions in dimensional analysis.   
Per example the formula for the time $t_f$ for an object to fall from the height $h$: 
$$ t_f = \sqrt{\frac{2h}{g}} $$
Using dimensional analysis, $dim \; h = L$ and $dim \; g = L/T^2$ , so 
$$ dim \; t_f = dim \; \sqrt{\frac{2h}{g}} = \sqrt{\frac{L}{LT^-2}} = \sqrt{T^2} = T$$
We find that the time $t_f$ is of dimension $T$, which is to be expected.
