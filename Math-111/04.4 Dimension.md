#alglin 
Le nombre d'éléments dans la base d'un espace vectoriel s'appelle la dimension. On écrit$$n = \text{dim }V$$
Si $V$ est un $\mathbb R$-espace vectoriel de dimension finie, alors
- Si un ensemble $E$ est un espace générateur de $V$, alors il existe une base $\mathscr B \subset E$
- Si $\{v_1, \dots, v_r\}$ est une partie libre de $V$, alors il existe une base $\{v_1, \dots, v_r\}\mathscr B$
