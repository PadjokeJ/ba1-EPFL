>[!Théorème] Méthode de diagonalisation orthogonale
>Soit $A \in M_{n \times n} (\mathbb R)$ une matrice symétrique. Pour la diagonaliser orthogonalement $A$, il faut faire les étapes suivantes.
>1. Déterminer le polynôme caractéristique $c_A (t)$ de $A$
>2. Trouver toutes les racines de $\lambda_1, \dots, \lambda_r \in \mathbb R$ distinctes de $c_A (t)$ telles que
>   $$c_A (t) = (-1)^n (t-\lambda_1)^{m_+} \dots (t - \lambda_r)^{m_r}$$
>3. Pour chaque $1 \le i \le r$, déterminer une base $\mathscr B_i$ de $E_{\lambda_i}$
>4. Pour chaque $1 \le i \le r$, utiliser le procédé de Gram-Schmidt afin de trouver une base orthonormée $\mathscr B'_i$ de $E_{\lambda_i}$
>5. La base $\mathscr B' = \mathscr B'_1 \cup \dots \cup \mathscr B'_r$ est une base orthonormée de $V = \mathscr R^n$
>6. La matrice $P = [id_V]_\mathscr{CB'}$, avec $\mathscr C$ la base canonique de $V$, est orthogonale et $P^T AP$ est diagonale
