# Définition

Un [système d'équations linéaires](01%20Systèmes%20d'équations%20linéaires) est dit homogène si tous les termes constants sont nuls

Un **système homogène** contient toujours au moins une solution (dont la solution ou toutes les variables sont égales à zéro)

-> Pour [échelonner](01.6%20Elimination%20de%20Gauss) on peut donc utiliser la matrice contenant uniquement les coefficients (matrice de coefficients) afin de le [résoudre](01.7%20Résolutions%20de%20systèmes%20linéaires) plus rapidement
