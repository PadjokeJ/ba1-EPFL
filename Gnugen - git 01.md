# Basic commands

Create a new project
locally
```bash
git init
```
using an existing repo on github/gitlab
```bash
git clone <repo url>
```


See what will be committed 
```bash
git status
```


Create a commit
```bash 
git add <files>
git commit
```


See the differences between last commit
```bash
git diff
```

# Branches

You can branch out from your current work

See the branches
```bash
git branch
```

Switch to a branch
```bash
git checkout <name>
```
using `-b`will create a new branch of that name

Merge with a branch 
```bash
git merge
```
