#aicc 
A function $f$ from a set $A$ to a set $B$, where any $A$ is assigned to only one element in $B$ ($f(a) = b, f(a) = c\iff c=b$)

We write $f : A \to B$ 
We write $f(a) = b$, if $b \in B, a \in A$

Also called **mappings** or **transformations**

## Terminology

- **Map:** $f$ *maps* $A$ to $B$
- **Domain:** $A$ is the *domain* of $f$
- **Codomain:** $B$ is the *codomain* of $f$
- for $f(a)=b$
	- **Image:** $b$ is the *image* of $a$
	- **Preimage:** $a$ is the *preimage* of $b$
- **Range:** the set containing all the images of points in $A$ is the range $f(A)$

## Subset of Domains

If $S\subseteq A$, then 
- the image of $S$ for $f$ is the subset of $B$ that contains the images of the elements of $S$
- $f(S) = \{t \mid \exists s \in S (t = f(s)\}$ <-> $\{f(s) \mid s\in S\}$

## Adding & Multiplying Functions

- REAL VALUED function -> codomain $\equiv \mathbb R$
- INTEGER VALUED function -> codomain $\equiv \mathbb R$

Functions with those domains can be added and multiplied

### Adding

- $(f_1  + f_2)(a) = f_1(a) + f_2(a)$
### Multiplying

- $(f_1 \cdot f_2)(a) = f_1(a) \cdot f_2(a)$

# Injection

A function is ==injective== if and only if 
$$f(a)=f(b) \to b=a, \forall b,a$$
A function is ==surjective== if and only if there is an element in $A$ mapped to every element in $B$ 
$$f(a) = b, \forall b \in B$$
A function is ==bijective== if and only if it is *surjective* and *injective*

## Inverse function

The inverse of $f$, written as $f^{-1}$, is the function from $B \to A$
$$f^{-1}(y)=x\iff f(x) = y$$

# Composition

We denote $f\circ g(x) = f(g(x))$ the composition of the function of the two functions $f : A \to B$ and $g : B \to C$

# Partial functions

A partial function is when for a function $f : A \to B$, we only consider the items of a subset $S \subseteq A$, called the *domain of definition*.

We say that $f$ is undefined $\forall x (x \in A \land x \notin S)$ 

>[!Example]-
>A function which takes an integer and returns only the integer square roots
>We have $f:\mathbb{Z \to N}, f(n) = \sqrt n \iff \exists m \in \mathbb N\; s.t.\; n = m^2$
