#aicc 

An algorithm is a finite set of well-defined instructions to perform a specified task.
In the context of computing, algorithms are implemented by computers.

>[!Example]
>**Find the maximum integer in a sequence**
>We have a temporary maximum variable set to the first integer
>We compare with the next integer in the sequence :
>- if the next is larger than the temporary maximum, set the temp max equal to the next integer
>- if else we do nothing
>Repeat the previous step if there are more integers to loop through
>When the algorithm finished, the temporary maximum is the maximum integer

## Specifying Algorithms

Algorithms can be specified in different ways :
- Natural language
- Pseudo-code
- A real coding language (not php)
