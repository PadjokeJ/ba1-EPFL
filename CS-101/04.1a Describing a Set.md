Elements are listed between braces

>[!Example]-
>Let $V$ be the vowels of the alphabet -> $V = \{a,e,i,o,u\}$

## Roster Method

List all the elements within the braces
If there are a lot of elements in a clear pattern, it is okay to use ellipses to omit some elements $(\dots)$ 

## Set Builder Notation

Use a predicate that the values have to follow $$S = \{x \mid P(x)\}$$
$P(x)$ can be expressed as predicate logic, or natural language.

## Interval Notation

Sets of real numbers contained within two values $a$ and $b$
Can contain the value (closed square brackets), or not contain it (open square brackets or just brackets)

We call them open $(a,b)$ or closed intervals $[a,b]$

# Set members

Sets can have other sets as "members"

# Empty Set

A set without any elements
Denoted $\emptyset = \{\}$ 

>[!Warning]
>The set $\{\emptyset\}$ is a set with one element !

# Universal Set

A set containing everything in the current domain of consideration.
