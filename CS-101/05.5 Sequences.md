>[!tldr] Definition
>A sequence is a function from a subset of the integers to a set $S$

Let $f:\mathbb N\to S$ be the function which defines a sequence
- We write $a_n$ to denote the image $f(n)$ of the integer $n$
- We call $a_n$ a term of th sequence
- We denote the whole sequence by $\{a_n\}$

## Arithmetic Progression

It is a sequence of the form 
$$a,\;a+d,\;a+2d,\;\dots,\;a+nd,\;\dots$$
where the initial term $a$ and the common difference $d$ are real numbers

It is denoted
$$f:\mathbb N\to S,\;f(n)=a+nd$$
## Geometric Progression

It is a sequence of the form
$$a,\;ar,\;ar^2,\;\dots,ar^n,\;\dots$$
Where the initial term $a$ and the common ratio $r$ are real numbers

It is denoted
$$f:\mathbb N\to S,\;f(n)ar^n$$

## Strings

A string is a finite sequence of characters from a finite set $A$ (an alphabet)

It is denoted
$$f:\{0,\;1,\;\dots,\;n\}\to A$$
When a string is empty, we denote it $\lambda$

They are important in computer science

## Lexicographic Ordering

The ordering used in dictionaries forms a lexicographic ordering
- discreet $\prec$ discrete, because $e\prec t$
- discreet $\prec$ discreetness, because the second string is longer
These are well ordered sets

# Explicit versus Recursive formulas

The explicit formula is when we can calculate a term at a certain $n$, i.e. $f(n)=n^2$

However we can specify terms of a sequence based on the previous terms and an initial condition

## Recurrence Relations

A recurrence relation for a sequence $\{a_n\}$ is an equation which expresses the term $a_n$ based on a finite number $k$ of preceding terms
$$a_n = f(a_{n-1},a_{n-2},\dots,a_{n-k})$$
We have the initial conditions as 
$$a_0,a_1,\dots,a_{k-1}$$
We can find an explicit formula for a given recurrence relation. We call this "solving the recurrence relation"

If such formula exists, it is called a closed formula

### Iterative approach - Forward

We start by listing the first terms of a relation
We then check to see if a pattern emerges

### Iterative approach - Backward

We start by listing the last terms $a_{n-i}$ of a relation
We then check if a pattern emerges

### Some questions to ask

- Are there repeated terms of the same value?
- Can you obtain a term from the previous term by adding or multiplying by an ammount (gives either geometric or arithmetic progressions)
- Can you obtain a term by combine the previous terms?
- Are there cycles among the terms
- Do the terms match those of a well known sequence?

## Fibonacci Sequence

It is a sequence defined as 
$$f_n = f_{n-1}+f_{n-2}, \quad f_0 = 0,\;f_1 = 1$$
