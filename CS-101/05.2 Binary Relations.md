>[!TLDR] Definition
>A binary relation *R* from a set $A$ to a set $B$ is a subset *R* $\subseteq A\times B$

>[!Example]-
>For $A=\{0,\;1\}$ and $B=\{a,\;b,\;c\}$
>$R_1 = \{(0,a),(0,b),(1,a)\}$ is a relation from $A$ to $B$
>$R_2 = \{(0,a),(1,b)\}$ is a relation from $A$ to $B$

A function $f:A\to B$ can also be a subset -> as a relation

## Relation on a Set Itself

>[!tldr] Definition
>A binary relation $R$ on a set $A$ itself is a subset of $A\times A$

## Reflexive Relations

A relation is **reflexive** $\iff (a,a)\in R,\quad \forall a\in A$

## Symmetric & Antisymmetric Relations

>[!tldr] Definition
>A relation is symmetric $\iff (b,a)\in R$ whenever $(a,b)\in R, \quad \forall a,b \in A$


>[!tldr] Definition
>A relation is called antisymmetric 
>$\iff (a,b)\in R$ and $(b,a) \in R \implies a=b, \quad\forall a,b \in A$

>[!Warning]
>Despite their naming, they are NOT opposite things

## Transitive relations

>[!tldr] Definition
>A relation is called transitive 
>$\iff (a,b)\in R$ and $(b,c)\in R \implies (a,c)\in R,\quad\forall a,b,c \in A$


## Combining relations

Given two relations, we can combine them using set operations

## Composition

If we have $R_1$ from $A$ to $B$, and $R_2$ from $B$ to $C$, then the composite of $R_1$ and $R_2$ is the relation from $A$ to $C$

We denote this with $R_1 \circ R_2$

## Equivalence

A relation on a set is called an equivalence relation if it is **reflexive**, **symmetric**, and **transitive**

We denote two elements related by equivalence $a\sim b$

### Equivalence classes

If $R$ is an equivalence relation on a set. The set of all elements that are related to an element $a$ of $A$ is the equivalence class of $a$.

We denote it as $\left[a\right]_R$
$$[a]_R = \{s\mid(a,s)\in R\}$$
