A problem is tractable if there exists an algorithm which solves it in $O(n^d)$ operations
This is the class P of polynomial complexity
If such an algorithm doesn't exist, then the problem is intractable

## The Class NP

The NP class is the problems in which the correctness of a solution can be verified in polynomial time. 
There doesn't exist a polynomial time algorithm for finding a solution
NP is nondeterministic polynomial time
- Every problem in NP can be solved in exponential time
- Is $P=NP$? (not known)
- Therefore the general assumption is that $NP \neq P$

## Example of a NP Problem

**Knapsack Decision Problem**
Given a set $S$ of $n$ items, with each item having a value and a weight, can we create a subset of value which is at least $V$ without exceeding the weight limit $W$
- no polynomial time algorithm
- Exponential algorithm: try out all possible subsets
