# Number of Strings

If we fix a property that our string has to meet, then we should be able to count how many strings can fit that property. (Ordered)

-> If our alphabet $X$ is the set of vowels $X=\{a,e,i,o,u\}$
-> We can make 625 different 4-letter words

This leads us to define the product rule

>[!Definition] Definition -- The Product Rule
>The number of sequences such that there are $a_i$ choices for $s_i$ after having chosen $s_1,s_2,\dots,s_{i-1}$, for each $i=1,2,\dots,n$ is exactly $a_1\cdot a_2 \cdot \dots \cdot a_n$
>
>In general -> If we have sets $S_1,S_2,\dots,S_n$, then we have $|S_1\times S_2 \times \dots \times S_n| = \prod_{i=1}^n \vert S_i \vert$

# Counting functions

How many functions are there from a set with $m$ elements to a set with $n$ elements

There are $n^m$ options

## Counting one-to-one functions

$m$ must be of $m \le n$

# The Sum Rule

>[!Definition] Definition -- The Sum Rule
>If we have multiple finite disjoint sets, then 
>$$\left\vert \bigcup_{i=1}^n S_i \right\vert = |S_1| + |S_2| + \dots + |S_n|$$

# The Subtraction Rule

>[!Definition] Definition -- The Subtraction Rule
>For two finite sets $A$ and $B$, we have
>$$|A \cup B| = |A| + |B| - |A \cap B|$$

# Permutation

What if we want to build a sequence of $r$ elements from a set $S$, with $|S|=n$, where all of the entries are distinct

We denote permutations as such -> $P(n, r)$

>[!Theorem]
>If $n$ and $r$ is a positive integer, with $1 \le r \le n$, then we have
>$$P(n, r) = n(n-1)(n-2)\dots(n-r+1)$$

>[!Corollary]
>$$P(n, r)={n!\over(n-r)!}$$

# Combinations

What if we want unordered selection where permutations are not a thing (all entries are distinct)

>[!Theorem]
>The combination $C(n,r)$ is given by
>$$C(n,r)={n! \over r!(n-r)!}$$

>[!Corollary]
>For a combination, the opposite is equal -> selection of r elements = selection of n - r elements
>$$C(n,r)=C(n,n-r)$$

>[!Example]- Example -- Dealing a specific poker hand
>How many pokers hands of five cards, which contain a full house can be dealt
>We pick a random card -> 13 different ranks
>We pick another card of another rank -> 12 different ranks left
>We then have 4 suits corresponding to each rank -> C(4,3) and C(4,2)
> ==UNFINISHED==

A combination with repetition of a set of distinct objects is an unordered selection where elements can occur multiple times

>[!Theorem]
>The number of $r$-combinations when repetition is allowed is
>$$C(n+r-1,r) = {(n+r-1)! \over r!(n-1)!}$$

# Permutations with Indistinguishable Objects

If objects are permutable without distinction, then the amount of permutations is given by
$$n! \over n_1! n_2! \dots n_3!$$
# Pigeonhole Principle

If $k + 1$ objects are placed into $k$ boxes -> then at least one box contains two or more objects

## Generalized version

If $N$ objects are placed into $k$ boxes, then there is at least one box containing at least $\lceil N / k \rceil$ objects
