Induction and Recursion
Are both approaches to proving results and solving problems
- Induction extends to  a problem of any size
- Recursion reduces a problem to the smallest possible size

## Induction

We assume that $P(k)$ is true, then if $P(k+1)$ is true, then it is true for all values
We start at a small value (such as $1$)

It is expressed by this rule of inference:
$$(P(1)\land\forall k(P(k)\to P(k+1))) \to \forall n P(n)$$
### Strong Induction

The inductive step is to show that al the propositions from the basis to $k$ imply that the proposition of $k+1$ is true

Sometimes simple induction cannot be used, so we can use Strong Induction instead.

## Inductively defined Sets and Structures

Induction can be used to define a set

Basic Step: Specifies an initial collection of elements
Inductive Step: gives the rules for forming new elements in the set from those already known to be in the set
