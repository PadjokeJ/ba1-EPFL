#aicc 
Sets have a few operators that result in another set. They correspond to the propositional logic operators.
They are associative and commutative operations.
# Union
All the elements which are either in one set or in the other or both:$$A \cup B := \{x\mid x \in A \lor x \in B\}$$

## Cardinality

Theorem: $|A \cup B| = |A| + |B| - |A \cap B|$
# Intersection
All the elements which are contained in both sets:$$A \cap B := \{x \mid x\in A \land x \in B\}$$

# Symmetric difference
The elements which are either in one set or the other, but not both:$$A\oplus B :=(A-B)\cup(B-A)$$

# Generalizing operations
If we have a collection of sets $A_1,\; A_2,\; \dots,\; A_n$ we can use the following notation:$$\bigcup_{i=1}^n A_i = A_1 \cup A_2 \cup \dots \cup A_n$$$$\bigcap_{i=1}^n A_i = A_1 \cap A_2 \cap \dots \cap A_n$$
# Set identities

## Proofs

There are multiple ways to prove that two sets are equivalent according to an identity: 
1. Use a set builder notation and propositional logic. Step by step proof
2. Prove that each set is a subset of the other
3. Verify that elements in the same combination of sets belongs to both or belongs to neither, using Membership Tables (kinda like truth tables)
