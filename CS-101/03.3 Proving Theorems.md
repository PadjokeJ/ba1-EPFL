# Proving theorems

To prove theorems of the form $\forall x(P(x) \to Q(x))$,
we show $P(c) \to Q(c)$
where $c$ is any element in the domain

==We only need to show that *q* is true if *p* is true==

### Trivial proofs

if we know that $q$ is true, then $p \to q \equiv T$

>[!Example]-
>

### Vacuous proofs

if we know that $p$ is false, then $p \to q$ is true

### Direct proofs

We assume that $p$ is true, then we use definitions axioms and other theorems with rules of inference, so that $q$ is true,

In the form $p \to q$ 

>[!Example]-
>Theorem : if $n$ is odd, then $n^2$ is odd too
>$p:=n \text{ is an odd integer}$
>$q := n^2 \text{ is odd too}$
>$n = (2k + 1)$ def.
>$n^2 = (2k + 1)^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1$
>since any integer mult 2 is pair (def), then this is odd

### Indirect proof: contraposition

We assume that $\lnot q$ is True, then we show that $\lnot p$ results

This works because $p \to q \equiv \lnot p \to \lnot q$

### Indirect proof: contradiction

We assume that $p$ and $\lnot q$ are True, then we use a direct proof, in a way that we produce a contradiction of this statement

This works because $p \to q \equiv (p \land \lnot q) \to F$ 

>[!Example]-
>if $n$ is odd, then $n^2$ is also odd
>We now have $n$ is odd and $n^2$ is even

>[!Example]- Example: $\sqrt 2$ is irrational
>Let's prove that $\sqrt 2$ is irrational
>>[!Definition]
>>A real number $r$ is rational if there exists integers $p$ and $q$, such that $r$ can be written as $r = p/q$, where $q \not = 0$, and $p$ and $q$ do not share any common factors
>
>We assume that $\sqrt 2$ is rational
>Hence there exists $a$ and $b$, such that $\sqrt 2 = a/b$, and $a$ and $b$ share no common factors (def)
>$2 = a^2/b^2 \iff 2b^2 = a^2 \iff a^2 \text{ is even}$ therefore, $a$ can be written as $a = 2c$
>Hence $2b^2 = 4c^2$ and therefore $b^2 = 2c^2
>$b$ is also even, and shares a common factor ($2$) with $a$
>THIS IS A CONTRADICTION!!

### Proof by cases

To prove a statement of the form $(p_1 \lor p_2 \lor \dots \lor p_n) \to q$
We can prove each case individually, case by case
Because $\left[ (p_1 \lor \dots \lor p_n) \to q \right] \iff \left[ (p_1 \to q) \land \dots \land (p_n \to q) \right]$ 
Each of the implications is a **case**

### Counterexamples

We know that in predicate logic, we can find a counter example to make $\forall x P(x)$ False, we only need ONE counterexample, this applies to theorems too

### Proofs of equivalence

To prove a theorem that is a biconditional statement (iff), we can show that $p \to q$ and $q \to p$ are true
