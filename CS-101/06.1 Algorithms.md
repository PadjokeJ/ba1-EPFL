# Linear Search Algorithm

Locates an item in a list by examining elements in a sequence one at a time, starting at the beginning

Pros :
- apply to any list
Cons :
- slow
- very slow if element not in list
# Binary Search

Linear search, but you are sure that the list is ordered in increasing order.

We look at the element at the middle of the list. If our desired element is smaller, we cut the top half, if our desired element is greater we cut the lower half, else if it is equal, we have our element. We repeat this process until the list we have only has one element within it. We return -1 if the last element in the list is not our desired one.

Pros :
- Very fast on big lists
- Very fast if element not in list
Cons :
- All elements must be comparable
- List has to be sorted

# Sorting

## Selection Sort

In the first pass, we find the minimum element of the list, and we put it into the first position

In the second pass, we find the second least element of the list, and we put it into the second position

Etc...

## Bubble Sort

We pass through a list
If we compare two elements. If they are out of order, we swap them. Then we step one element to the right.

If when we did a pass no elements had to be swapped, then the list is sorted.

## Insertion Sort

We compare the 2 first elements
If the second one is smaller than the first, we put it in front
We move to the third element
We compare it to the second
If it is smaller, we compare it to the first
If it is, we put it in front of the first
etc...
