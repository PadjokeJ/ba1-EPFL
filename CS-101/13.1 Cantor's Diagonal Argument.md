>[!Theorem] Cantor's Diagonal Argument
>We assume that we can list a set in a sequence indexed by the positive integers $\{a_n\}$ -> we assume it is countable
>We associate each element of $\{a_n\}$ to the decimal representation of each element of the set
>We show that we can build an element which is not in $\{a_n\}$
>By contradiction, our initial assumption is then false

IE the digit made up by the diagonal's opposite has digits which never always differ from the other numbers -> the set is uncountable
