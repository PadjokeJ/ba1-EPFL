## Summation

Given a sequence $\{a_n\}$, we are interested in adding the terms that range from $a_m$ to $a_n$
We denote this by
$$\sum_{j=m}^na_j$$
>[!Warning] The upper limit of a sum can be infinite!

## Summation over Sets

For a set $S$, we can denote
$$\sum_{j\in S}a_j$$
## Sums as Sequences

We can define a sequence by a summation formula
$$s_n = \sum_{j=0}^nj$$
