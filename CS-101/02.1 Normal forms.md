# Disjunctive normal form

A **disjunction** of one or more **conjunctions**  
A **full** DNF is where each variable or its negation is represented only once  
We can find it using a truth table

# Conjunctive normal form

A **conjunction** of one or more **disjunctions**  
A **full** CNF is where each variable or its negation is represented only once  
We can find it using a truth table

# Finding a normal form WITHOUT truth tables

Step by step : 
1. Eliminate equivalences and implications (only using $\land$, $\lor$ and $\lnot$)
2. Move negations INSIDE of brackets
3. Use distributive and associative laws to get all terms within brackets
