A relation $R$ on a set $S$ is called a partial ordering if it is reflexive, antisymmetric and transitive

A set $S$ with a partial ordering $R$ is called a poset (for Partial Ordering SET), and it is denoted as $(S,R)$

>[!Example]
>$$R = \{(a,b)\in \mathbb{Z\times Z}\mid a \ge b\}$$
>It is a partial ordering on $\mathbb Z$
>The poset is $(\mathbb Z, \ge)$

To define the ordering relation in arbitrary posets we use the symbol $\preceq$

## Comparability

The elements within a poset $(S,\preceq)$ are comparable if $a\preceq b$ or $b \preceq a$. If these conditions are false, then $a$ and $b$ are called incomparable.

If $a,b\in S$, it is NOT NECESSARY THAT EITHER $a\preceq b$ or $b \preceq a$

### Total ordered and well-ordered sets

If a poset $(S, \preceq)$ and every element in $S$ is comparable, then it is totally ordered. 

If a poset's $\preceq$ is totally ordered, and every nonempty subset has a least element, then it is well ordered

## Hasse Diagrams

A way to represent a poset with a graph. 
- Nodes are the elements
- Edges connect elements that have a relation
- Self relations are not represented
- Transitive relations are not represented (as they are implicit)
	- if $a\preceq b$ and $b\preceq c$, the obviously $a\preceq c$, but it will not be represented
- The edges are not directed (assumed they are pointing upwards)

## On Cartesian Product

Given two posets $(A_1, \preceq_1)$ and $(A_2,\preceq_2)$, the ordering on $A_1\times A_2$ is defined by specifying that $(a_1, a_2)$ is less than $(b_1,b_2)$
$$(a_1,a_2)\prec(b_1,b_2)$$
Which is verified either if $a_1\prec_1 b_1$ or (if $a_1=b_1$ and $a_2\prec_2b_2$)
