We take a damped harmonic oscillator, but we apply an external driving force that has a sinusoidal form:
$$\vec F_e = F_e \vec e_x = F_0 \cos(\omega_et)\vec e_x$$
![[Pasted image 20251113121502.png]]

$$\ddot x + 2\gamma \dot x + \Omega_0^2x = f_0 \cos(\omega_et)$$
With $f_o = {F_0\over m}$

# 1 - Method for solving

The general method to use is
1. Search for $x_2(t)$, which is the general solution of the equation **without** the forcing term, $f(t)=0$
2. Search for $x_1(t)$, which is a **particular** solution of the equation **with** the forcing term

The general solution will be given by 
$$x(t)=x_1(t)+x_2(t)$$
We find that this equation tends towards $0$ when $t$ goes to infinity. $x_2(t) \to 0$. We therefore have in this case
$$x(t)\simeq x_1(t)$$

Since it is an oscillator, we will assume that $x_1(t)$ will be of the form
$$x_1(t)=A(\omega_e)*\cos\left(\omega_et+\phi\left(\omega_e\right)\right)$$
Let us use the complex notation $\downarrow$ for solving the original formula
$$\underline a = ae^{i\theta}=a*(\cos\theta + i \sin \theta)$$
-> We can therefore get
$$\ddot{\underline x} + 2\gamma \dot{\underline x}  + \Omega_0^2\underline x = f_0 e^{i\omega_et}$$
And by getting the real part of the equation we have a solution of the form
$$\underline {x_1} = \chi_0 e^{i\omega_e t}$$
We therefore define $\chi_0 = A(\omega_e)e^{i\phi(\omega_e)}$, and we can simplify the time derivatives of $x$
$$\begin{array}l
\underline{\dot x} &= \chi_0 (i\omega_e)e^{i\omega_e t} \\
\underline{\ddot x} &= -\chi_0 \omega_e^2 e^{i\omega_e t}
\end{array}$$
We then re-implement them into the original formula and get
$$-\chi_0\omega_e^2 + 2 i\gamma \, \chi_0 \, \omega_e + \chi_0 \, \Omega_0^2 = f_0$$
We can factorize $\chi_0$ and find
$$\chi_0 = {f_0 \over -\left(\omega_e^2 - \Omega_0^2 + 2i\gamma \omega_e\right)} = A(\omega_e)e^{i\phi(\omega_e)}$$
We then can finally obtain
$$A(\omega_e)={f_0 \over \sqrt{(\omega_e^2-\Omega_0^2)^2 + 4\gamma^2\omega_e^2}} $$
$$\tan\phi = {2\gamma\omega_e \over \omega_e^2-\Omega_0^2}$$

# 2 - Analysis

We start being inside of a Transient regime, in which $x_2(t)$ has not yet converged to $0$. Once $x_2(t)$ is small enough, we are in a Steady State Regime.  

## Analysis of the Steady State

We have $x(t) = x_1(t) = A(\omega_e)*\cos(\omega_e t + \phi(\omega_e))$

The frequency for which $A$ reaches its maximum is called the **resonance frequency**, it is written $\omega_{res}$

We can also find them by using $g(\omega_e)=(\omega_e^2-\Omega_0^2)^2 + 4 \gamma ^2 \omega^2_e$, and by differentiating it
$$\begin{cases}
\omega_e = 0\\
\omega^2_e = \Omega_0^2-2\gamma^2
\end{cases}$$

We also get 
$$\omega_{res}=\sqrt{\Omega_0^2 - 2\gamma^2}$$
Which means that there is no resonance if $2\gamma^2\gt \Omega_0^2$
### Quality factor

We define a quality factor 
$$Q = {\Omega_0\over 2\gamma}$$
The condition to obtain a resonance is $Q\gt \frac1{\sqrt2}$ 
The larger $Q$ is, the greater the maximum amplitude is
