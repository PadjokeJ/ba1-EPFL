AKA Logical form
assume the following rule holds :
$p \to q$
If we know 
$p$
Then we can conclude 
$q$ 
==this is called an argument form==
- true for all $q$ and $p$

it is written :
$$\begin{align}
p & \to & q \\
p \\
\hline
\therefore   q
\end{align}$$
An **argument** is a sequence of propositions : 
- every proposition is called a premise
- the last statement is the conclusion
- the argument is ==valid== if the premises imply the conclusion

An **argument form** is when an argument is always valid, for any value of $p$ or $q$ (tautology)

**Inference rules** are argument forms that are useful, and therefore can be used to make up more complex argument forms

# building the form

## using a truth table

1. Build the complete truth table for all premises and the conclusion
2. Cross out all the rows where at minimum one premise is False
3. Check whether the row of the conclusion only contains True
