A **subset** is a **set** in which every element is also an element of its **superset**

We note $A \subseteq B$, if $A$ is a subset of $B$
We note $B \supseteq A$, if $B$ is a superset of $A$

Another notation using predicate logic is $\forall x (x \in A \to x \in B)$

## Proofs

Since a subset requires every element to be also in its superset, then **to prove that a set is not a subset** we can find a **counterexample** 

## Proper Subset

A set is a **proper subset** if it is a subset but is not equal to its superset
$A \subseteq B \land A \neq B$ 
$\forall x(x \in A \to x \in B) \land \exists x (x \in B \land x \notin A)$ 
We note $A \subset B$ 

# Power set

The power set, written $\mathcal P (A)$, is the set of all the subsets of $A$
>[!Example]
>If $A = \{a, b\}$ -> $\mathcal P(A) = \left\{\emptyset, \{a\}, \{b\}, \{a,b\}\right\}$
