#aicc 

This consists in breaking up a problem in smaller sized problems -> i.e Binary Search

# Steps 

1. Divide
   - if $n\gt1$ divide the problem of size $n$ into smaller problem
   - else solve for size $=1$
2. Conquer solve the subproblems the same way (recursively)
3. Merge the problems into a solution

>[!Example] Binary search
>```python
>def bin_search(x, l, r, sorted_list):
>	if l > r:
>		return -1
>	m = (l + r) // 2
>	if x < sorted_list[m]:
>		return bin_search(x, l, m - 1, sorted_list)
>	elif x > sorted_list[m]:
>		return bin_search(x, m + 1, r, sorted_list)
>	return m
>```
