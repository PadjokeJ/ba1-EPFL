#aicc 

We've used formal power forms as formal objects

However we can use them to define a sequence using the coefficients. This results in a **generating function**

>[!Example]+ Example with recurrence
>If we have the recurrence $a_n = 3a_{n-1}-2a_{n-2}, \quad \forall n \ge 2$
>To determine the sequence of coefficients we need to provide two initial values
>Let's use $a_0 = 1$ and $a_1 = 3$
>We can then compute each term using the recurrence function
>$$a_2 = 3\cdot 3 - 2\cdot 1 = 7$$
>$$a_3 = 3\cdot 7 - 2 \cdot 3 = 15$$
>$$\vdots$$
>
>However, we can also find a formula to get a general term:
>We have the recurrence $a_n = 3a_{n-1}-2a_{n-2}$
>We multipily both sides by $x^n$:
>$$a_nx^n = 3a_{n-1}x^n-2a_{n-2}x^n$$
>We can notate this as a formal power sum:
>$$\sum_{n\ge2}^\infty a_nx^n=3\sum_{n\ge2}^\infty a_{n-1}x^n-2\sum_{n\ge2}^\infty a_{n-2}x^n$$
>Lets move some $x$ around:
>$$\sum_{n\ge2}^\infty a_nx^n=3x\sum_{n\ge2}^\infty a_{n-1}x^{n-1}-2x^2\sum_{n\ge2}^\infty a_{n-2}x^{n-2}$$
>The sums are not correctly indexed:
>$$\sum_{n\ge2}^\infty a_nx^n=3x\sum_{n\ge1}^\infty a_{n-1}x^{n-1}-2x^2\sum_{n\ge0}^\infty a_{n-2}x^{n-2}$$
>We can rewrite it as $A(x)$:
>$$A(x)-a_0 -a_1x = 3(A(x)-a_0)-2x^2A(x)$$
>We can solve $A(x)$
>$$A(x)-a_0-a_1x = 3x(A(x)-a_0)-2x^2A(x)$$
>$$A(x)(1-3x+2x^2)=a_0+a_1x-3xa_0=1+3x-3x=1$$
>$$A(x)=\frac1{1-3x+2x^2}$$
>$$A(x)=\frac1{(1-2x)(1-x)}$$
>$$A(x)=\frac2{1-2x}-\frac1{1-x}$$
>Now we expand out the result using $\frac1{1-ax}=1+ax+a^2x^2+\dots$
>$$A(x) = 2(1+2x+2^2x^2+\dots) - (1 + x + x^2 + \dots)$$
>$$A(x) = \sum_{n\ge0}^\infty(2^{n+1}-1)x^n$$
>We therefore have $a_n = 2^{n+1}-1$


## Summary

- Write down the recurrence
- Multiply both sides by $x^n$
- Sum over the range of validity (no divs by 0)
- Rewrite the expressions in terms of $A(x)$
- Rearrange the terms in order to get $A(x)p(x)=q(x)$
- Divide both sides by $p(x)$: $A(x)=\frac{q(x)}{p(x)}$
- Factorize $p(x)$ as $p(x)={\LARGE \Pi}_i(1-a_ix)$, where $1\over a_i$ are the roots of the polynomials
- If all roots are distinct, then we have $q(x)\over p(x)$ can be written as $\sum_i \frac{\beta_i}{1-\alpha_ix}$
- Determine $\beta_i$ by solving a linear sys eq.
- Expand ${\beta\over 1-\alpha x} = \beta(1+\alpha x+\alpha^2 x^2+\dots)$
- Sum up all the terms to get a formula for $a_n$
