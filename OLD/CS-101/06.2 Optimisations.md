# Greedy algorithms

It makes the "best" choice at each step

>[!Example] EXAMPLE : Cashier's algorithm
>Find for an ammount of $n$ cents the least total number of coins using only quarters, dimes, nickels and pennies.
>The greedy approach would be to pick the greatest value coin possible each time
>```rust
>fn find_coins(val: i32) -> Vec<i32> {
>  let coins: i32[] = [25, 10, 5, 1];
>  let mut val = val;
>  let mut given: Vec<i32> = vec![];
>  for i in 0..4 {
>    given.push(val/coins[i]);
>    val -= given[i]*coins[i];
>  }
>  given
>}
>```

# Proving optimality

>[!Example] EXAMPLE : Cashier's algorithm
>Theorem : the greedy alg is the best option
>
>we have the coins $(\hat d, \hat n, \hat c)$ by greedy
>and the optimal coins $(d, n, c)$
>
>If we have $2$ nickels, then we can replace that with a single dime, if we have $5$ cents we can replace it with a single nickel.
>
>Optimal solution has $n \le 1$ and $c \le 4$
>Greedy solutions we also have $n \le 1$ and $c \le 4$
>We have $d \le \hat d$
>We know that if $d\lt \hat d$, then the solution is not optimal
>Therefore $d = \hat d$ 
>Then greedy must be optimal for the cashier's algorithm
>
>However if we remove nickels then the greedy is no longer optimal
