>[!Definition] Definition -- Terms
>An **experiment** is a procedure in which we have multiple outcomes that are possible
>The **sample space $S$** of the experiment is the set of possible outcomes
>An **event E** is a subset of the sample space

>[!Definition] Definition -- Laplace
>If $S$ is a finite sample space of equally likely outcomes, and $E$ is an event, which is a subset of $S$, then the probability of the event is denoted
>$$p(E) = {\lvert E \rvert \over \lvert S \rvert},\quad \forall E, 0 \le p(E) \le 1$$

>[!Theorem]
>The probability of an event not happening (denoted $\bar E$) is given by 
>$$p( \bar E) = 1 - p \left( E \right)$$

>[!Theorem] The probability of Union of Events
>The probability of either of two events happening is given by
>$$p(E_1 \cup E_2) = p(E_1) + p(E_2) - p(E_1 \cap E_2)$$

>[!Definition] Definition -- independence
>Two events $E$ and $F$ are independent if
>$$p (E \cap F) = p(E) p(F)$$
>>[!Theorem] 
>>If $E$ and $F$ are independent, then
>>$$p(E \mid F) = p(E)$$
>If all events are independent as such, then they are pairwise independent
>

>[!Definition] Definition -- Bernoulli Trials
>Given an experiment that can have only two possible outcomes
>- Each performance is called a Bernoulli Trial
>- One outcome is success, the other is failure
>- If $p$ is the probability of success, then we have $q$ the probability of failure with $p + q = 1$
>
>>[!Theorem] Independent Bernoulli Trials
>>The probability of exactly $k$ successes in $n$ independent Bernoulli trials is given by
>>$$C(n, k) \cdot p^k \cdot q^{n - k}$$


>[!Theorem] Bayes Theorem
>If we have two events which have a non null probability, then we have 
>$$p(F \mid E) = {p(E \mid F) p(F) \over p(E)}$$

## Random Variables

>[!Definition] Definition -- random variable
>(Which is neither random nor a variable)
>Is a function $X : S \to \mathbb R$ from the sample space $S$ to the set of real numbers, which assigns a real number to each possible outcome
>
>Unlike events, it is not a set of outcomes or an outcome
>>[!Example]
>>If the random variable maps to the amount of times that a coin is heads
>>$Y = 1$ -- TTH, HTT, THT
>>$Y \lt 2$ --  TTH, HTT, THT, TTT
>>$Y \ge 2$ -- HHT, HTH, THH, HHH
>>$Y = y$

>[!Definition] Definition -- Distribution of a Random Variable
>The list of all the possible values that the random variable can take. It is given by
>$$p(X = r) = \sum_{s \in S \mid X(s) = r} p(s)$$

>[!Definition] Definition -- Probability Mass Function
>This is a way to plot the probabilities of each event
>$$\sum_{r \in X (S)} p(X = r) = \sum_{r \in X(S)} \sum_{s \in S \mid X(s) = r} p(s) = \sum_{s \in S} p(s) = 1$$

>[!Definition] Definition -- Expected Value
>We have the expected value of a random variable given by
>$$E(X) = \sum_{s \in S} p(s) X(s)$$

>[!Theorem] Linearity of Expectation
>The sum of all Expected Values of each random variables is equal to the expected value of the sum of all random variables -> the relation is linear

>[!Theorem] Expected value of Bernoulli Trials
>The expected value of bernoulli trials is given by $X=np$
