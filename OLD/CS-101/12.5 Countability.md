## Cardinality

For a set we say that its cardinality is the amount of distinct elements within it
We denote it $\vert S \vert$

### Injection/Surjection and Cardinalities

If there is an injection from a set $A$ to a set $B$, then the cardinality of $A$ must be less or equal to the other's cardinality : $\vert A \vert \le \vert B \vert$

If there is a surjection from a set $A$ to a set $B$, then the cardinality of $A$ is greater or equal to the other's cardinality : $\vert A \vert \ge \vert B \vert$

## Countable Sets

>[!Definition]
>A set that is either finite of has the same cardinality as a set of positive integers is countable
>
>A set that is not countable is uncountable

### Properties

A subset of a countable set is countable
A cartesian product of finitely many countable sets is countable
The union of finitely many countable sets is countable
The set of all strings associated to an alphabet is countable
