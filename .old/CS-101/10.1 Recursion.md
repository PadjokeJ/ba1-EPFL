>Recursive step:
>- Give a rule for finding a value based on the previous values

>Recursive definition of $n!$
>$$f(0)=1$$
>$$f(n)=(n)\cdot f(n - 1)$$

# Recursively defined functions on Strings

>[!Definition]
>The set $\Sigma*$ of strings over the alphabet $\Sigma$ is defined inductively by
>- Basis : $\lambda \in\Sigma*$ (where $\lambda=''''$) 
>- Inductive : if $w \in\Sigma*$ and $x\in\Sigma$, then $wx\in\Sigma*$

>[!Definition]
Via recursion - 
>- Basis: $l(\lambda)=0$
>- Recursive: $l(wx)=l(w)+1$ if $w\in\Sigma*$ and $x\in\Sigma$

>[!Theorem]
>$l(xy) = l(x)+l(y)$, with $x$ and $y$ in the alphabet $\Sigma$
# Recursive algorithms

An algorithm is recursive if it solves a problem by reducing it to a problem of a smaller size.
For it to find a solution, it has to reduce the problem to an initial case.

>[!Example]
>Recursively calculate a factorial number
>```rust
>fn factorial(n: u32) -> u32 {
>	if n == 0 {
>		return 1;
>	}
>	factorial(n - 1) * n
>}
>```

Iterative algorithm :
- Start with the base case and apply the recursive definition.

>[!example]
>```rust
>// recursively
>fn pwr_rec(a: f32, p: i32) -> f32 {
>	if p == 0 {
>		return 1;
>	}
>	a * (pwr_rec(a, p - 1) as f32)
>}
>// iteratively
>fn pwr_ite(a: f32, p: i32) -> f32 {
>	let mut res: f32 = 1;
>	for i 0..p {
>		res = a * res;
>	}
>	res
>}
>```
