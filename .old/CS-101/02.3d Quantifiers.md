We can express how much of the [[02.3b Universe|universe]] is True

# Universal Quantifier

It is a quantification of a [[01.1 Propositional Logic|propositional function]] ([[02.3 Predicate logic|predicate]]), where "P($x$) is true for all values of $x$ that come from the [[02.3b Universe|universe]] $U$"

Notation: 

$\forall x \; P(x)$ 

Read "for all x, P(x)"

## Truth values

it is TRUE when EVERY value of $U$ makes $P(x) = T$   

it is FALSE when AT MINIMUM ONE value of $U$ makes $P(x) = F$
(counter example)

# Existential Quantifier

It is a quantification of a [[01.1 Propositional Logic|propositional function]] ([[02.3 Predicate logic|predicate]]), where "$P(x)$ is true if there is an element of $U$ that makes $P(x) = T$"

Notation

$\exists x \; P(x)$ 

Read "There is $x$, such that $P(x)$"

## Truth values

it is TRUE when AT MINIMUM ONE value of $U$ makes $P(x) = T$

it is FALSE when ALL values of $U$ make $P(x) = F$

# Uniqueness

It is a quantification of a [[01.1 Propositional Logic|propositional function]] ([[02.3 Predicate logic|predicate]]), where "$P(x)$ is true if there is one and only one element of $U$ that makes $P(x) = T$"

Notation
$\exists ! \; P(x)$ 

## Truth values

it is TRUE when THERE IS ONLY ONE value of $U$ makes $P(x) = T$

it is FALSE when THERE ISNT ONLY ONE (more than one or zero) values of $U$ make $P(x) = T$

# Finite domains

if the [[02.3b Universe|domain]] $U$ is finite, we can list all the elements of $U$

$U = \{x_1, x_2, \dots, x_n\}$, where $n \in \mathbb N$ 

# Precedence

the quantifiers $\forall$ and $\exists$ have a higher [[01.1 Propositional Logic#Precedence|precedence]] than any other connective from [[02.3 Predicate logic|predicate logic]]

# Binding

We can *bind* a variable of a propositional function

- $P(x)$ is with a **free variable $x$** 
- $\forall x P(x)$ has a **bound variable** $x$ 

## Scope

We call *the scope* the part of a logical expression that is bound to a variable

- $\forall x (P(x) \lor Q(x))$
- $\forall x P(x) \land Q(y)$

# Validity 

We call a statement **valid** if a predicate with a bound variable (with a quantifier) if it is true (See [[01.1 Propositional Logic#Tautology|tautologies]])

## Satisfiable

We call a statement **satisfiable** if a statement is TRUE for *SOME* values

## Unsatisfiable

if a statement is neither valid or satisfiable, then it is unsatisfiable

# Negating Quantified Expressions

There is an equivalent quantifier for a negation of a quantifier -> using De Morgan's Law #cheatsheet 

$\lnot \exists x$ -> $\forall x \lnot P(x)$

$\lnot \forall x P(x)$ -> $\exists x \lnot P(x)$

# Nested quantifiers

You can use quantifiers sequentially when two variables are independent -> nesting

Example :
$\forall x\exists y(x + y = 0)$

# Order of Quantifiers

>[!Warning]
>There is a difference between $\forall x\exists y(x + y = 0)$ and $\forall x\;\exists y(x + y = 0)$
