>[!TLDR] Definition
>A FPS is an expression of the form
>$$\sum_{n=0}^\infty a_nx^n$$
>Where $a_n$ are coefficients (which are either real or complex most of the times)

This sum is **formal** : We are not interested in its proprieties (ie whether it converges or not)

## Addition

We can do additions on FPS
$$A(x) + B(x) = \sum_{n=0}^\infty (a_n+b_n)x^n$$
We add the coefficients (like polynomials)

## Multiplication

We can also multiply them as if they were polynomials :
$$A(x)\cdot B(x) = \sum_{n=0}^\infty\left(\sum_{k=0}^n(a_kb_{n-$})x^n\right)$$
>[!Tip]
>To compute the n-th coefficient of the multiplication, we only have to do a finite sum of operations, no matter how great $n$ is. The fact that both sums add up to infinity is not a problem.

## Division

Division is possible WITH SOME CAUTION!! -> division is not always defined in reals.

Let's use the definition of division in reals to get a definition for FPS': 
$a\over b$$=c\iff a = b\cdot c,\quad b\neq0$  
-> We define division using multiplication

>[!TLDR] Definition
>Let $A(x)$ and $B(x)$ be two FPS'. We can say that 
>$$\frac{A(x)}{B(x)}=C(x) \iff A(x)=B(x)\cdot C(x)$$

That means we have to solve for $C(x)$:
$$A(x)=a_0 + a_1x+\dots=(b_0c_0)+(b_0c_1+b_1c_0)x+\dots$$
We can solve the equation, such as $b_0c_0$ equals to $a_0$. In this case we have $c_0 = \frac{a_0}{b_0}$ 

We can use this recipe for all coefficients, we solve for $c_i$

>[!Example]
>solve for $c_1$
>$$a_1 = b_0c_1 + b_1c_0$$
>We already know $c_0$:
>$$c_1 = \frac{a_1-b_1c_0}{b_0}$$

We can apply this in general, with the formula
$$c_n = \frac{a_n-\sum_{k=1}^nb_kc_{n-k}}{b_0},\quad b_0\neq0$$
