# R' is rotating uniformly inside of R, with A = O

this means that we have $\vec v_{\mathcal R}(A) = \vec 0$ -> $\vec a_{\mathcal R} (A) = \vec 0$

P is inert in $\mathcal{R'}$  

rotation is a constant, therefore $\vec \omega = \overline {constan}\vec t$ 
$\dot {\vec \omega} = \vec 0$  

$\vec v_{\mathcal R} (P) = \vec \omega \wedge \vec{OP}$
$\vec a_{\mathcal R}(P) = \vec \omega \wedge (\vec \omega \wedge \vec{OP})$ 

This is quite literally just a spherical coordinates analysis
