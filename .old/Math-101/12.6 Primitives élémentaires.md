#analyse 

>[!Définition] 
>On appelle intégrale indéfinie la fonction donnée par 
>$$\int f(x) dx \quad \text{ou} \quad F(x) + C$$

On a comme propriétés ->
$$\int k f(x) dx = k \int f(x) dx$$
$$\int (f(x) + g(x)) dx = \int f(x) dx + \int g(x) dx$$
$$\int f'(g(x)) g'(x) dx = f(g(x)) + C$$
$$\int {g'(x) \over g(x)} dx = \log \lvert g(x) \rvert + C$$

On a également des primitives qui sont élémentaires

| $f(x)$           | $F(x)$                        |
| ---------------- | ----------------------------- |
| $k$              | $kx + C$                      |
| $x^a$            | ${x^{a + 1} \over a + 1} + C$ |
| $1\over \sqrt x$ | $2\sqrt x + C$                |
| $e^x$            | $e^x + C$                     |
| $a^x$            | ${a^x \over \log a} + C$      |
| $\sin x$         | $- \cos x + C$                |
| $\cos x$         | $\sin x$                      |
| $\tan x$         | $-\log \|\cos x\| + C$        |
|                  |                               |
