#analyse 

Pour les intégrales avec une ou les deux bornes qui sont infinies

On fait tendre la/les borne(s) vers l'infini, en utilisant le théorème fondamental de l'analyse

>[!Théorème] Théorème, intégrales de type II
>- Soit $f : [a, +\infty[ \to \mathbb R$
>  $$\int_a^\infty f(x) dx := \lim_{L \to +\infty} \int_a^L f(x) dx$$
>- Soit $f : ]-\infty, b] \to \mathbb R$
>  $$\int_\infty^b f(x) dx := \lim_{L \to -\infty} \int_L^b f(x) dx$$

>[!Théorème]
>Pour tout $a \gt 0$,
>$$\int_a^\infty {dx \over x^p} = \begin{cases} 
>{1 \over (p - 1) a^{p - 1}} && \text{converge} && \text{si } p \gt 1, \\
>+\infty && \text{diverge} && \text{si } p \le 1 \end{cases}$$
